# Manbo media

## Reaction frames

The original `brain-off.webp`, `joy.webp`, and `loading.webp` reaction frames
were AI-generated for this project on 2026-08-27, then compressed with
[`sharp`](https://sharp.pixelplumbing.com/).

The supplied meme pictures were used as references for the square close-up
framing and comic expressions. The generated character has its own short bob,
cream forelock, turquoise X hair clip, and dark hoodie.

## Thinking loop

`thinking-loop.mp3` is an AI-generated meme-music clip prepared for this
project on 2026-08-27 from a reference track confirmed reusable for this use.
It is trimmed, compressed, and loop-ready for the Manbo thinking effect.

The reaction frames and audio are bundled locally and embedded in the client
runtime. They require no external image or audio requests.
